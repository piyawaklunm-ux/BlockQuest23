# BlockQuest: ผจญภัยเรียนรู้ในโลก 3 มิติ

## รายละเอียดเกม
BlockQuest เป็นเกมผจญภัยในรูปแบบสามมิติ (3D) ที่ให้ผู้เล่นสำรวจสถานที่ต่าง ๆ ภายในเกม ทำภารกิจ ตอบคำถาม และสะสมคะแนนจากการเล่น ผู้เล่นสามารถเลือกตัวละคร เดินสำรวจแผนที่ และใช้คะแนนที่ได้รับเพื่อเลือกซื้อไอเทมภายในเกมได้

## วิธีการเล่นเกม

1. **เริ่มเกม:** เปิดเกมและกดปุ่มเริ่มเล่น (Start) เพื่อเข้าสู่โลกของเกม
2. **ควบคุมตัวละคร:** ใช้ปุ่ม W, A, S และ D เพื่อเดินไปข้างหน้า ซ้าย ถอยหลัง และขวา ตามลำดับ
3. **กระโดด:** กดปุ่ม Spacebar เพื่อกระโดด
4. **สำรวจสถานที่:** เดินสำรวจหมู่บ้านและเมืองเพื่อค้นหาสถานที่ทำภารกิจ
5. **โต้ตอบกับสิ่งต่าง ๆ:** กดปุ่ม E เมื่ออยู่ใกล้สิ่งของหรือจุดที่สามารถโต้ตอบได้
6. **ทำภารกิจ:** อ่านคำถามที่ปรากฏบนหน้าจอ แล้วเลือกคำตอบที่คิดว่าถูกต้อง
7. **สะสมคะแนน:** ตอบคำถามเพื่อสะสมคะแนนและใช้คะแนนตามระบบที่เกมกำหนด
8. **เปลี่ยนมุมมอง:** ใช้ปุ่มเปลี่ยนมุมกล้องภายในเกม เพื่อสลับระหว่างมุมมองบุคคลที่หนึ่งและบุคคลที่สาม
9. **เปลี่ยนแผนที่:** กดปุ่ม M เพื่อเดินทางระหว่างหมู่บ้านและเมือง
10. **เลือกซื้อไอเทม:** เปิดร้านค้าภายในเกมเพื่อเลือกซื้อไอเทมตามคะแนนที่มี
11. **ดูกระเป๋าสิ่งของ:** เปิดคลังสิ่งของเพื่อตรวจสอบไอเทมที่มีอยู่

## ปุ่มควบคุมเกม

- W: เดินไปข้างหน้า
- A: เดินไปทางซ้าย
- S: เดินถอยหลัง
- D: เดินไปทางขวา
- Spacebar: กระโดด
- E: โต้ตอบกับสิ่งของหรือจุดทำภารกิจ
- M: เปลี่ยนแผนที่ระหว่างหมู่บ้านและเมือง
- เมาส์: ควบคุมมุมมองและเลือกคำตอบ

## เทคโนโลยีที่ใช้

- **HTML:** ใช้สร้างโครงสร้างหน้าเกม
- **CSS:** ใช้ตกแต่งหน้าตาและจัดรูปแบบองค์ประกอบต่าง ๆ
- **JavaScript:** ใช้พัฒนาระบบการเล่น การควบคุมตัวละคร และการโต้ตอบภายในเกม
- **Three.js:** ใช้สร้างฉากสามมิติ ตัวละคร วัตถุ แสง และกล้อง
- **Visual Studio Code:** ใช้เขียนและแก้ไขโค้ดเกม

## วัตถุประสงค์ของเกม

1. เพื่อสร้างความสนุกสนานผ่านการสำรวจโลกจำลองสามมิติ
2. เพื่อส่งเสริมการเรียนรู้ผ่านภารกิจและการตอบคำถาม
3. เพื่อฝึกทักษะการคิด การตัดสินใจ และการแก้ปัญหา
4. เพื่อประยุกต์ใช้เทคโนโลยีเว็บในการพัฒนาเกมเพื่อการเรียนรู้
